# Rashed Omar's Portfolio Website

An interactive, responsive portfolio website showcasing my skills, projects, and professional experience as a Senior Full Stack Engineer.

## Features

- Interactive terminal with command-line interface
- Dark/Light mode toggle with custom themes
- Responsive design for all device sizes
- Animated project cards with flip effect
- Interactive network infiltration game
- Skills visualization with tooltips
- Interactive timeline for work experience
- Contact form and social media links

## Technologies Used

- HTML5
- CSS3 with custom animations
- Vanilla JavaScript
- Particles.js for background effects
- FontAwesome for icons
- Google Fonts
